# engine.grids — grids()

(experimental) Placement grids: world <-> cell, occupancy derived from world records, per-cell layers, placement preview (grids() module)


## Methods and properties
- `grids.add(name: string, opts?: { cell?, origin?, size?, zone?, flat?, y?, … }) → Grid` — Create a grid. cell: edge length (m, default 1); origin: world [x, z] of the min corner of cell [0, 0]; size: [cells wide, cells deep] (omit = unbounded); zone: level name (tiles only show there); flat: max height difference under a footprint (m, default 0.5); y: height of level 0 (m; default the ground under each cell), levelHeight: meters per level (default 3; level n is at y + n * levelHeight); mapping: { toCell(x, z) => [i, j], center([i, j]) => [x, z] } replaces the square cell <-> world math (one place: toCell, toWorld, tiles, flatness); layers: authored cells { zone: [[i, j, { buildable: true }], ...] } (content/grids.js): the baseline a save diffs against, so a save keeps only changed cells. Example: `const room = engine.grids.add('room', { cell: 0.5, origin: [-3, -3], size: [12, 12], zone: 'house' })`
- `grids.get(name: string) → Grid | null` — A grid by name, or null when there is none
- `grids.list() → Grid[]` — All grids (a new array)
- `grids.define(name: string, rule: import("./Grid.js").GridRule)` — Register what can be placed and its rules. size [w, d] in cells (default [1, 1]); kind of the world record (default the item name); occupy: the occupancy layer it takes (default 'main'): things in different layers share a cell ('floor' tile, 'main' table, 'wall' lamp), two in one layer do not; ground: allowed engine.groundType values; layer: { layerName: field } that must be truthy on every cell (reason 'not' + Field, e.g. notBuildable); flat: max height difference (overrides the grid's); fields: copied into the record; can(e, { grid, cell, rotation, cells, level }): your own rule. Example: `engine.grids.define('tower', { size: [2, 2], layer: { zone: 'buildable' }, fields: { range: 6 } })   // tower defense`
- `grids.preview(opts: { grid, item, from?, rotate?, rotation?, draw? }) → { cell, rotation, ok, code, rotate, place, … }` — Show where an item would go: the target cell under the pointer ('pointer', default), in front of the player ('front') or from your function, turned by the input action rotate (default name 'rotate'; the game binds it, e.g. presets.bindings.gridRotate; the engine binds no key itself), light when can() passes, dark otherwise (neutral tool colors; grids({ ok, bad }) override them). draw: false = no visual; (engine) => ({ update(view), hide(), dispose() }) = your own; pv.material is the default box's three.js material. place() runs grid.place with what is shown. Example: `engine.input.bind({ place: ['Mouse0'], ...presets.bindings.gridRotate });   // the game's own bindings const pv = engine.grids.preview({ grid: 'field', item: 'tower' }); engine.onFrame(() => { if (engine.input.pressed('place')) { const r = pv.place(); if (!r.ok) toast(engine, engine.t('grid.' + r.code)); } });`
- Properties:
  - `ok: any` Preview color where it can be placed, read when a preview is made
  - `bad: any` Preview color where it cannot be placed, read when a preview is made
  - `previewOpacity: number` Opacity of the preview box, read when a preview is made
  - `previewHeight: number` Height of the preview box (meters), read when a preview is made
  - `tiles: Record<string, Record<string, any>>` Tile colors by layer name, { layer: { field: color } } (first truthy field of a cell wins), read when a layer is made
  - `tileLift: number` Height of tiles above the ground (meters), read when a layer is made
