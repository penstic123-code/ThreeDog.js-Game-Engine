# engine.post (PostFX)

- `post.object() → any` — The three.js EffectComposer the chain runs in, for reading (pass list, sizes, its targets), or null while no post work has run yet (built the first time an effect or MSAA is on; it is not built here, so asking never costs a half-float target). Read-only by rule, not by lock: the engine owns it, rebuilds composer.passes whenever the chain changes and disposes it with the engine. To add a pass use look.post.add, to own the whole chain look.post.replace (recipe 52). Why public: a game reading the chain had to dig into an internal field (review 2026-11-03)
- `post.targets() → { renderTarget1, renderTarget2, readBuffer, writeBuffer } | null | …` — The composer's render targets, for reading (sample the last frame's color or depth in a game pass, check formats / samples), or null while there is no composer. renderTarget1 / renderTarget2 are the ping-pong pair. During the chain readBuffer is a pass's input and writeBuffer its output; EffectComposer swaps them after every pass with needsSwap (most passes; the scene RenderPass does not). The last pass draws to the canvas and still swaps, so after the frame (engine.onRender(fn, { when: 'after' })) neither target holds the final picture: writeBuffer holds the input of that last pass (readBuffer when the last pass does not swap) and readBuffer is stale. For the final image, render into a target of your own. Owned by the engine like object(): it resizes them, changes samples on setAntialias and adds a depth texture when an effect needs depth; do not dispose them or swap their textures.
- `post.get(name: string) → PostHandle | undefined` — (experimental) Read-only record of an added effect (name, slot, order, enabled, params), or undefined. Change one with engine.look.post.set({ 'bloom.strength': 0.6 })
- `post.setAntialias(on: boolean)` — (experimental) Turn MSAA (antialiasing of the post chain) on or off. It is a render target setting, not a look part. Example: `engine.post.setAntialias(false);`
- `post.list() → { name, slot, order, enabled }[]` — (experimental) Effects in render order: [{ name, slot, order, enabled }]
- Properties:
  - `antialias: boolean` MSAA on (read-only; switch with post.setAntialias(on))
  - `active: boolean` Whether any post work runs (antialias or an enabled effect)
