# engine.rigid — rigid(opts?: RigidOptions)

Real physics, Rapier (rigid() module, needs collision)

- Options `RigidOptions`:
  - `gravity?: number` Gravity (m/s², negative points down), default -9.81
  - `terrainRing?: number` How many rings of chunks around the player get terrain colliders, default 1. A body outside them freezes until the player comes near (entry.enabled false, describe().rigid.frozen), because it would fall through the ground: raise this for a car or ball that must keep moving far away
  - `buoyancy?: boolean` Whether there is buoyancy, default true
  - `buoyancyForce?: number` Buoyancy strength (1 = just floats), default 1.6
  - `waterDrag?: number` Drag in water, default 2.5
  - `floatLine?: number` Buoyancy "waterline": an object starts floating when its center is this many meters below the water surface, default 0.3
  - `floatDepth?: number` Buoyancy reaches its maximum this many meters further down, default 0.8
  - `treeColliderHeight?: number` Height (meters) of vegetation collision pillars (tree trunks), default 6
  - `treeRadius?: number` Trunks get collision cylinders only in chunks within this many meters of the player or a moving rigid body (the rest are covered by engine.collision for characters), default 16
  - `playerCapsule?: { halfHeight: number; radius: number }` Player capsule size (meters), default computed from engine.movement radius / height

## Methods and properties
- `rigid.addBox(mesh: Object3D, opts?: RigidBoxOptions) → RigidEntry | null` — Add a box (crate). Physics is ready after engine.start() (or on engine:ready): called before, it throws in development, a release build warns once and returns null
- `rigid.addBall(mesh: Object3D, opts?: RigidBallOptions) → RigidEntry | null` — Add a ball; null only as in addBox: a release build, called before physics is ready
- `rigid.addHull(mesh: Object3D, opts?: RigidBodyOptions) → RigidEntry | null` — Add a convex hull (irregular objects such as rocks and barrels); null only as in addBox: a release build, called before physics is ready
- `rigid.ragdoll(who: any, opts?: RagdollOptions) → Ragdoll | null` — (experimental) Turn a skinned character limp in one call; rd.remove() returns it to animation. who: a Character, an NPC handle, a character id or a skinned Object3D. Its mover, animator, capsule and camera yield until then; calling again on the same one pushes it again and returns the same ragdoll. Not saved: any load ends it. A skeleton it cannot read throws, naming the missing parts.
- `rigid.impulse(entry: RigidEntry, impulse: Vec3Like)` — Give it a push: impulse vector impulse (Vector3 / [x, y, z] / { x, y, z }), e.g. impulse(ball, [0, 3, 5])
- `rigid.setPosition(entry: RigidEntry, position: PositionLike)` — Teleport to position (velocity is zeroed)
- `rigid.addWheeled(mesh: Object3D, opts: VehicleOptions) → Vehicle | null` — Turn a model into a wheeled vehicle (Rapier ray-cast vehicle controller: cars, karts, carts); remove it with vehicle.remove() (anyone inside gets out first). Before physics is ready it throws in development (release: warns, null), like addBox. Boats, mounts and mechs are the game's own objects with the same seat interface
- Properties:
  - `ready: boolean` Is the physics engine ready (downloaded and initialized at start())
  - `bodies: RigidEntry[]` All physics bodies
  - `rapier: any` (experimental) The Rapier library itself: its shape follows the Rapier version
  - `world: any` (experimental) The Rapier world: its shape follows the Rapier version
  - `playerBody: any` (experimental) The player's Rapier kinematic body and capsule collider (follow the player position every step; used for collision when mover: 'rapier'; the capsule is off while driving)
  - `playerCollider: any` (experimental) The capsule collider on playerBody
  - `playerCapsule: { halfHeight: number; radius: number }` Player capsule size (meters)
  - `vehicles: Vehicle[]` All vehicles
  - `stats: { bodies: number; active: number; colliders: number }` Statistics

## Data structures
- **RigidBodyOptions** Parameters for adding a physics body
  - `id?: string` Stable id (e.g. the world record id): saves keep this body's pose, rotation, velocities and sleep under it, and a load hands them back to the body with this id, also one built after the load. Without an id the body is not saved. Unique among live bodies and vehicles
  - `mass?: number` Mass (kilograms), default 1
  - `friction?: number` Friction, default 0.7
  - `restitution?: number` Restitution 0–1, default 0.1
  - `damping?: number` Linear damping, default 0.05
  - `angularDamping?: number` Angular damping, default 0.1
  - `fixed?: boolean` Fixed in place (only blocks other things)
- **RigidEntry** (extends Handle) A physics body (the handle returned by addBox / addBall / addHull)
  - `id?: string` The id it was added with (saves name it by this), undefined without one
  - `body: any` Rapier rigid body (translation(), mass(), setLinvel()…); newGame / a load rebuild the world, so read entry.body again instead of keeping it
  - `collider: any` Rapier collider
  - `mesh: Object3D` The matching three.js model (position is written by physics every step)
  - `object: Object3D` Same as mesh
  - `enabled: boolean` Whether it is being simulated: false while it is outside the terrain colliders (rigid({ terrainRing })), where it would fall through the ground
  - `volume: number` Volume (cubic meters, used for buoyancy)
  - `damping: number`
  - `angularDamping: number`
  - `wet?: boolean`
  - `remove()` — Remove this rigid body (the model was passed in by you and is not deleted; call engine.remove(entry.object) when done). Casting / receiving shadows follows the model's own castShadow / receiveShadow
- **VehicleOptions** Parameters of rigid.addWheeled()
  - `id?: string` Stable id (default 'vehicle1', 'vehicle2'... in creation order): saves name the player's vehicle and the vehicle's body state by it; give one when the creation order varies
  - `wheels: VehicleWheel[]` Wheels (at least 3)
  - `mass?: number` Mass (kilograms)
  - `engineForce?: number` Throttle force, default 800
  - `brakeForce?: number` Brake force, default 20
  - `maxSteer?: number` Max steering angle (radians), default 0.5
  - `suspension?: { rest?: number; stiffness?: number; damping?: number }` Suspension: rest natural length (meters), stiffness, damping
  - `seats?: Vec3Like[]` Seat positions relative to the body (meters): the first drives, the rest ride; each gets out beside its own seat. Default one at the body center
  - `hideDriver?: boolean` Hide whoever sits in it, default true; false keeps riders visible on their seats, turning with the vehicle (bikes, open carts, karts)
  - `camera?: { distance?: number; height?: number }` Camera distance and height while driving (meters)
  - `size?: number[]` Body collision box size [width, height, depth] (meters); if omitted, taken from the model's bounding box (wheels excluded)
  - `friction?: number` Tire grip, default 1.5
  - `exitOffset?: number` Distance from the side of the body when getting out (meters), default 0.8
- **VehicleWheel** A wheel: position relative to the body (meters), radius (meters), steer can steer, drive is powered, object is the wheel model that spins
  - `position: Vec3Like`
  - `radius: number`
  - `steer?: boolean`
  - `drive?: boolean`
  - `object?: Object3D`
- **Vehicle** (extends RigidEntry, Rideable) A vehicle (returned by rigid.addWheeled, faces the model's +Z). player.enter(vehicle) gets in; with interactions installed, press the interact key nearby to get in / out
  - `id: string` Stable id (rigid.addWheeled({ id })); saves name the player's vehicle by it
  - `object: Object3D` Body model (the mesh you passed in)
  - `body: any` Rapier rigid body
  - `controller: any` Rapier vehicle controller (DynamicRayCastVehicleController)
  - `wheels: VehicleWheel[]`
  - `seats: number`
  - `passengers: Character[]`
  - `hideDriver: boolean`
  - `seatPosition(seat?: number) → Vector3` — World position of a seat (default 0, the driver's)
  - `exitPosition(seat?: number) → Vector3` — Where to get out of a seat (outside the door on that seat's side, world coordinates)
