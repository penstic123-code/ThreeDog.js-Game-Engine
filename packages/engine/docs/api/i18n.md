# engine.i18n (I18n) — engine.i18n: string tables; engine.t(key, params) fetches text and replaces {name} with params

- `engine.t(key: string, params?: Record<string, any>) → string` — Get UI text (i18n): {name} in the text takes params.name, {key:action} the label of the key bound to that action; a key with no text comes back as itself. Example: `engine.t('shop.buy', { name: 'Fish' });`
- `i18n.add(tables: StringTables)` — Register string tables (never overrides text the game gave). Example: `engine.i18n.add({ 'zh-CN': { 'shop.buy': '购买 {name}' }, en: { 'shop.buy': 'Buy {name}' } });`
- `i18n.setLocale(l: string)` — (experimental) Switch language ('auto' picks from the browser like createEngine)
- `i18n.has(key: string) → boolean` — Whether the key exists
- Properties:
  - `fallback: string` (experimental) Language used when a key is missing in the current one (default 'en')
  - `locale: string` (experimental) Current language, e.g. 'zh-CN' ('zh' and 'zh-Hans' resolve to it, 'en-US' to 'en'). Read-only: setLocale changes it, and tells i18n:change
  - `languages: string[]` (experimental) All available languages
