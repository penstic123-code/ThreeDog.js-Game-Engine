# engine.i18n (I18n) — engine.i18n: string tables; t(key, params) fetches text and replaces {name} with params

- `i18n.add(tables: StringTables)` — Register string tables (never overrides text the game gave). Example: `engine.i18n.add({ 'zh-CN': { 'shop.buy': '购买 {name}' }, en: { 'shop.buy': 'Buy {name}' } });`
- `i18n.setLocale(l: string)` — Switch language ('auto' picks from the browser like createEngine)
- `i18n.has(key: string) → boolean` — Whether the key exists
- `i18n.t(key: string, params?: Record<string, any>) → string` — Fetch text; params replace {name}, {key:action} shows the key label. Example: `engine.i18n.t('shop.buy', { name: '鱼' });`
- Properties:
  - `fallback: string` Language used when a key is missing in the current one (default 'en')
  - `locale: any` Current language, e.g. 'zh-CN' ('zh' and 'zh-Hans' resolve to it, 'en-US' to 'en')
  - `languages: string[]` All available languages
