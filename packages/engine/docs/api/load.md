# engine.load (Load) — engine.load: the sources the world is loaded around

- `load.source(position: any, opts?: LoadSourceOptions) → LoadSource` — Add a load source: the world around position is loaded (terrain chunks, colliders, nearby models, stream entries) until remove() or until. position may be live (an Object3D or Vector3 that moves) or a function. detail 'simple' loads only terrain and hlod proxies (a far view); physics defaults to true for 'full'; pass false for a camera that only needs a picture. radius caps every loader's range (default: each loader's own range). until: a Promise (removed when it settles) or a function checked every frame (removed when it returns true). Example: `const dest = engine.load.source([800, 0, 300], { radius: 64 }); await dest.whenReady; engine.player.placeAt([800, 0, 300]); dest.remove();`
- `load.teleport(position: any, opts?: { radius?, move?, timeout? }) → Promise<void>` — Load the destination first, then move: resolves after the player (engine.focus without one) is placed. Until the destination is ready (terrain chunks, collision, nearby models) the player stays where it is. move replaces the default placement (for a vehicle or a custom character). timeout (seconds of frame time, default 60; Infinity waits forever): when the destination is still not ready, the Promise rejects (code load-timeout, naming the loaders still waiting) and the player is not moved. Example: `await engine.load.teleport([800, 0, 300]);`
- `load.readyCheck(name: string, fn: (source: LoadSource) => boolean) → { remove(): void }` — Register a readiness check for loaders: fn(source) returns whether this loader finished what that source asks for. For module authors whose loader reads load sources; games only read source.ready. Example: `engine.load.readyCheck('props', s => s.detail !== 'full' // props.queued === 0)`
- `load.list(pick?: { detail?, physics? }) → LoadSource[]` — Sources with fresh positions, filtered: { detail: 'full' } for models and stream entries, { physics: true } for colliders, no filter for terrain
- `load.reach(s: LoadSource, range: number) → number` — A loader's range for a source: its own range, capped by the source radius
- Properties:
  - `player: LoadSource` Built-in source at the gameplay anchor (world.anchor, else the player, else engine.focus): full detail and physics
  - `camera: LoadSource` Built-in source at the camera focus engine.focus: full detail, no physics
