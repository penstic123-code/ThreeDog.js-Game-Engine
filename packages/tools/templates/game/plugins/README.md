# plugins/

Each `.js` file here is plugged in at `engine.start()` by what it exports, with no line in main.js: an Object3D goes in the scene, a three.js Pass in the post chain, a Material or a ShaderPatch `{ slot, glsl, roles }` into `look.materials`, a module `{ name, type, install }` through `engine.use`. Order is by file name (`10-fog.js` before `20-bloom.js`); `plugins.json` `{ "order": [...], "off": ["20-bloom"] }` reorders or switches one off; files starting with `_` are helpers and are not plugged. `threedog lib pull` puts code entries here. `describe().slots` lists what each file plugged and what it affects. More: THREE.md "Plugins folder".
