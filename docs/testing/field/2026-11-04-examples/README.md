- 改造前：master（8301190f，还没有 look/ 文件夹）。改造后：分支 fix/example-pictures。

## 为什么会暗

改造前，引擎默认给一张中性的房间环境贴图，占环境光的一半，普通的 Lambert 材质也会吃到这份光。改造时只把另一半（半球光）写进了 look/，这半光就丢了。半球光照到侧面时只是天空色和地面色的平均，所以背光面又暗又偏蓝。
